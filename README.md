# Shelly Construction Website

A modern, professional construction company website built with HTML, CSS, and JavaScript. Designed to be deployed on GitHub Pages with a premium dark and gold theme.

## Features

- **Responsive Design**: Fully mobile-friendly layout
- **Modern UI**: Dark theme with gold accents
- **Static Site**: 100% static, compatible with GitHub Pages
- **Contact Form**: Integrated with Formspree for serverless contact functionality
- **Gallery**: Project showcase with lightbox functionality
- **WhatsApp Integration**: Direct chat button for customer inquiries

## Pages

- **Home**: Hero section, services overview, featured projects, company highlights
- **About**: Company story, mission, and team information
- **Services**: Detailed service offerings with descriptions
- **Projects**: Gallery of completed construction projects
- **Contact**: Contact form with multiple contact methods

## Technology Stack

- HTML5 Semantic Markup
- CSS3 with Flexbox and Grid
- Vanilla JavaScript (ES6+)
- Formspree for contact form handling
- Font Awesome for icons
- Google Fonts for typography

## Deployment

This website is designed to be deployed directly to GitHub Pages:

1. Push the code to a repository named `shelly-construction`
2. Enable GitHub Pages in repository settings
3. Select the main branch as source
4. The site will be live at `https://username.github.io/shelly-construction`

## Contact Form Setup

To enable the contact form:
1. Sign up at [Formspree](https://formspree.io/)
2. Create a new form
3. Replace the form action URL in `contact.html` with your Formspree endpoint
